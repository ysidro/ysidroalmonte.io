## 5. Proyectos para el portafolio de Upwork

Publicar primero entre cuatro y seis proyectos. Cada entrada debe incluir una portada consistente, problema, responsabilidad, solución, tecnologías y resultado verificable.

### Proyecto 1 — WooCommerce Product Personalization Platform

**Título:**

> Custom WooCommerce Product Personalization Platform

**Descripción:**

> Rebuilt a WooCommerce storefront for personalized acrylic and canvas products. Customers can upload an image, preview the product, select customization options, and carry the uploaded asset and processing metadata through cart, checkout, order management, and fulfillment.
>
> I developed the custom WordPress and WooCommerce logic, image-processing workflow, storefront architecture, and performance improvements. The current stack uses WordPress, WooCommerce, Timber, Twig, Svelte, Tailwind CSS, AWS, and Cloudflare.

**Tecnologías:** WordPress, WooCommerce, PHP, Timber, Twig, Svelte, Tailwind CSS, AWS, Cloudflare.

### Proyecto 2 — Real Estate API Sync

**Título:**

> WordPress Real Estate API Synchronization System

**Descripción:**

> Developed a custom WordPress integration that synchronizes property listings from an external real-estate API. The system maps external records to structured Custom Post Types, updates only changed fields, preserves editorial data, and uses stable identifiers to prevent duplicate listings.
>
> I designed the data model, API client, mapping layer, write process, retry behavior, scheduling, and operational logging. Synchronization replaced recurring manual listing entry and improved consistency between the source platform and WordPress.

**Tecnologías:** PHP, WordPress, REST API, Custom Post Types, MySQL, WP-Cron.

### Proyecto 3 — Custom WooCommerce Payment Gateway

**Título:**

> Secure WooCommerce Payment Gateway Integration

**Descripción:**

> Built a WooCommerce payment gateway for a Dominican Republic payment processor that did not provide an official plugin. The integration includes checkout fields, client-side and server-side validation, transaction handling, webhook signature verification, idempotent callbacks, and order-status management.
>
> Payment confirmation is driven by the verified server-to-server response rather than the customer redirect, reducing the risk of false payment confirmation.

**Tecnologías:** PHP, WooCommerce, JavaScript, Payment APIs, Webhooks, WordPress Hooks.

### Proyecto 4 — CreaThink Tools

**Título:**

> Privacy-First Browser Tools with Payments and Product Analytics

**Descripción:**

> Designed and developed a collection of browser-based tools for image compression, social-media resizing, and QR generation. File processing happens in the browser to reduce unnecessary uploads and protect user privacy.
>
> The product includes Paddle payments, signed webhook validation, Cloudflare infrastructure, D1 persistence, user entitlements, and an internal KPI dashboard that tracks the acquisition and conversion funnel.

**Tecnologías:** Next.js, React, TypeScript, Cloudflare Workers, D1, Paddle, Webhooks.

### Proyecto 5 — CreaThink Beacon

**Título:**

> WordPress Monitoring Platform with Go and PostgreSQL

**Descripción:**

> Developed a WordPress agent and external monitoring platform that collects site health data, reports signed heartbeats, performs remote uptime checks, and evaluates security, maintenance, infrastructure, and availability rules.
>
> The system uses HMAC authentication, AES-256-GCM credential encryption, SSRF-resistant uptime checks, PostgreSQL persistence, finding lifecycle management, scheduled workers, and a dashboard for monitoring multiple sites.

**Tecnologías:** WordPress, PHP, Go, PostgreSQL, Docker, HMAC, AES-256-GCM, REST API.

**Estado:** producto propio en desarrollo. Evitar presentarlo como trabajo de cliente o como servicio con usuarios pagados hasta disponer de esa evidencia.
